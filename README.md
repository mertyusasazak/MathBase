# ∂ MathBase - Knowledge Repository

Bitirme projesi olarak geliştirilmiş, yapay zeka destekli matematiksel bilgi deposu.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda test etmek için API erişim anahtarları proje içine (`.env.local`) hazır olarak tanımlanmıştır. Ekstra bir ayar yapmanıza gerek yoktur.

1. Proje dizininde terminali açın.
2. Bağımlılıkları yükleyin:
  
   npm install

3. Veritabanını (Prisma) başlatın:

   npx prisma generate

4. Uygulamayı çalıştırın:

   npm run dev


Uygulama **http://localhost:3000** adresinde çalışmaya başlayacaktır.
